 PHP Gaming Chatroom
A PHP-based gaming chatroom web application that allows users to communicate in real time using a browser-based interface.
 Features

- User registration and login
- Real-time chat functionality
- Gaming chat rooms
- Session-based authentication
- MySQL database integration
- Simple and responsive UI
- WebSocket-based real-time messaging


##  Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Apache Server (XAMPP / WAMP / LAMP)


##  Project Structure

myproject/
├── index.php
├── login.php
├── register.php
├── chat.php
├── logout.php
├── db.php
├── assets/
├── sql/
└── README.md



##  How to Run the Project

1. Install **XAMPP / WAMP / LAMP**
2. Place the project folder inside:
htdocs/
3. Start **Apache** and **MySQL**
4. Create a MySQL database
5. Import the SQL file from the `sql` folder
6. Update database credentials in `db.php`
7. Open browser and visit:
http://localhost/myproject
